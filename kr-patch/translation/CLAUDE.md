# 환세취호전 번역 작업 — 세션 시작 시 필독

이 폴더에서 JP→KR 번역 요청을 받으면 매번 다음을 지킨다.

**근거 문서 우선순위**

1. `GUIDE.md` (이 폴더) — 취호전 전용 수정 지침. 최우선.
2. `../../../gensei-pc98/translation/GUIDE.md` — 환세 시리즈 공통 지침
   (GitHub `flvrdoyster/gensei-pc98` sync로 원격 조회 가능).
3. 이 문서 — 위 둘에서 반복적으로 놓친 실수만 압축한 체크리스트. 새 규칙을 만드는 문서가
   아니라 **주의 환기용**이다.

**충돌 시**: 취호전 코퍼스의 기존 관례(= 이 폴더 `GUIDE.md`)가 시리즈 공통 지침을 이긴다.
전각/반각, 더듬음 구분자 등에서 실제로 정반대인 항목이 있다(아래 "표기 규칙" 참고).

## 1. 이름

- `アターホー` → **아타호** ("아터호" 아님 — 시리즈 3-1 장음 `ー` 생략 규칙)

  `黒い道着の拳士（青帯）` → `검은도복권사(파란띠)`

## 2. 캐릭터 말투

### 2-1 대원칙

**확정 어미 목록 밖의 어미로 "자연스럽게" 의역하지 않는다.** 캐릭터 대사를 번역하기 전에
`GUIDE.md` 4-1(주연 3인)·4-2(조연·보스) 표를 먼저 확인한다. 조연·보스(백호권사범·창룡·
주작·현무·론/치호 등)는 노인체/하오체/존댓말이 캐릭터마다 완전히 달라서 특히 주의.

동시에 **어미표는 허용 목록이지 강제 목록이 아니다.** 원문 서법(추측·확인·의문)을 어미
일관성보다 우선한다(GUIDE 1-4). 표에 있는 어미로 원문에 없는 단정·명령을 만들지 말 것.

### 2-2 주요 3인 어미 — 문장 기능별 분류표 (2026-08)

`GUIDE.md` 4-1의 어미 목록은 코퍼스 빈도순 나열이라 문장 기능별로 나뉘어 있지 않다. 아래는
**기능별로 재정리**한 것으로, 주요 3인만 대상이다.

- 표기: `(N)` = translation.json **confirmed 대사 실측 건수**, `*` = 표본 없이 톤으로 유추(미검증)
- 이 표는 캐릭터 간 배타가 아니다 — `~야`·`~네`처럼 여러 캐릭터가 공유하는 어미가 있다.
  **한 캐릭터 안에서 문장 기능을 가르는 용도**로 쓴다.

| 캐릭터 | 평서·단정 | 의문 | 청유·명령 | 추측 | 감탄·확인(깨달음) |
|---|---|---|---|---|---|
| **아타호** | ~야(6) / ~일세 / ~라고 | ~건가？(3) / ~인가？(1) / ~ㄹ까？(1) | ~함세(청유) / ~하게(4·명령) | ~겠지 / ~겠군(3) / ~는걸(1) / ~는데(3) | ~군·~로군(11) / ~잖아(4) / ~구만 / ~네(2) |
| **스마슈** | ~야(2) / ~거야 / ~다구 | ~냐？(1) / ~야？(3) / ~지？(3) / ~ㄹ까？(1) | ~하자*(청유) / ~해*(명령) | ~는데(5) / ~겠지* | ~군(5) / ~잖아(3) / ~네(2) / ~라고 |
| **린샹(존댓말)** | ~어요(3) / ~예요(4) | ~나요？* | ~하세요(1) | ~겠죠(1) | ~죠(4) / ~네요(3) / ~군요(2) |
| **린샹(반말)** | ~야(2) / ~어(3) | ~냐？* | ~해* | ~는데(3) / ~겠지(1) | ~네(2) / ~잖아(2) / ~거든* |

**아타호 `~군` 계열 주의**: `~군/~로군`(11건)은 **깨달음·확인**이고 `~겠군`(3건)이 **추측**이다.
`이상한 장치로군`(확인) ↔ `아이템은 못 얻겠군…`(추측). 섞어 쓰면 서법이 틀어진다.

**표준어 표기와 어긋나는 코퍼스 표기 주의**: `~구먼`이 국립국어원 표준어이지만, 코퍼스
실측은 `구만`이 156건, `구먼`이 3건 — confirmed 대사에도 `구만`이 다수(`위험할 뻔했구만`,
`배가 고프구만` 등). GUIDE 1-1 원칙(정식 번역, 명백한 오탈자 아니면 기존 관례 유지)에 따라
**이 프로젝트에선 `~구만`을 쓴다.** 표준어와 코퍼스 관례가 갈리는 다른 어미도 있을 수 있으니
헷갈리면 표준어를 그냥 쓰지 말고 코퍼스로 확인할 것.

### 2-3 린샹 — 반존대 방침 (2026-08 최신 지시)

일괄 반말도 일괄 존댓말도 아니다. **상대를 보고 위 표의 존댓말 행 / 반말 행을 고른다.**

| 상대 | 어투 |
|---|---|
| 아타호·연장자 | 존대 |
| 스마슈 | 반말 |
| 그 외 일반(3인칭 언급·다수 상대 등) | 반존대(해요체) = 존댓말 행 |

- *주의 1*: `GUIDE.md` 4-1 본문은 "판단 보류, 기존 존대 유지"라고 돼 있으나 **이 반존대
  방침이 최신 지시**이므로 이쪽을 따른다.
- *주의 2 — 미해결*: confirmed 대사 `아타호 바보！ 정말 싫어！`(offset 1067794)는 아타호가
  자리에 없는 **혼잣말 + 감정 폭발** 장면인데 반말이다. 감정이 격해지는 자리에서 반말로
  무너지는 패턴이 있는 것으로 보이나 방침에 반영돼 있지 않다 — 해당 장면이 나오면 굴에게 확인.
- 실측 참고: 린샹 confirmed 대사의 종결어미는 존대 35 : 반말 25로, GUIDE가 기술한 "존댓말이
  압도적"보다 실제로는 훨씬 섞여 있다(방침 재검토 시 근거).

## 3. 표기 규칙 (시리즈 공통 지침과 정반대인 항목 주의)

| 항목 | 취호전 | 시리즈 공통 |
|---|---|---|
| 문장부호·숫자·공백 | **전각만** (`！？　１２３`) | 반각 |
| 더듬음 구분자 | **쉼표** `아，아니` / `뭐，뭐라구` | 공백 |

- 물결표는 `∼`(U+223C)만. `～`(U+FF5E)·`~`(반각)는 게임 폰트에서 깨진다.
- 문장 끝 부호는 `！ ？ …`만, **마침표 금지**.
- 시스템 메시지·내레이션은 평서체(`얻었다`, `있다`) — GUIDE 2-4.

## 4. 과잉 번역 자가점검 (반복 실수)

번역 표를 내놓기 전에, **단어마다 "원문에 없는 함의를 얹었는가"를 한 번씩 점검**한다.
특히 실력·정도·감정 강도를 나타내는 단어는 원문 단어의 실제 뜻보다 세게 옮기기 쉽다.

**실제로 저지른 오류 사례**: `使い手`(다루는 사람/쓰는 사람) → `달인`(達人, 실력자)으로 오역.
`使い手`엔 숙련도에 대한 함의가 전혀 없는데 "달인"을 얹어버림 — GUIDE 1-2⒜(과한 의역, 원문에
없는 정보량 얹기)에 해당하는 전형적 실수.

체크리스트(제출 전 훑을 것):
- 실력·정도 형용사/명사(달인·고수·엄청·최고 등)를 쓴 자리가 있다면, 원문에 그 수준을 뜻하는
  단어(達人·名人·凄い·最高 등)가 실제로 있는지 원문을 다시 봄
- 감탄사·부사 강도를 원문보다 세게/약하게 옮기지 않았는지 확인
- 표에 다 옮긴 뒤 JP 원문과 KR을 한 줄씩 다시 나란히 읽으며 "이 단어가 어디서 왔는지" 각각
  짚을 수 있는지 확인 — 짚을 수 없는 단어가 있으면 그게 얹은 것

## 5. 작업 스타일

- **대조는 굴이 한다.** 기존 `translation.json`과 비교하지 말고 **JP 원문만 보고** 옮긴다.
- **의미 전달 > 직역 강박.** 줄 단위로 토막내지 말고 문맥이 자연스럽게 이어지게 옮긴다.
- **길이 제약은 이 단계에서 신경 쓰지 않는다.** 바이트 맞추기는 반영 단계의 별도 작업
  (GUIDE 1-3 "검토 라운드의 분업").
- 출력 형식: `화자 | JP | KR안` 표. 화자는 대사 앞 이름 줄에 나온 그대로 적는다.
- **낯선 어휘·고유명사는 표 아래에 별도 "어휘 해설" 섹션**으로 붙인다(고사성어, 사수(四獸)
  같은 배경지식, JP 특유의 말버릇 연출 등).
