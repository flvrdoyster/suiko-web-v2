# 환세취호전 KR 번역 개정 지침

> 이 문서는 **정식 발매된 KR판 번역을 저본으로 한 전면 개정**의 기준을 정리한다.
> 작업하면서 발견한 규칙·용어·판단 기준을 여기에 계속 누적한다.

**"전면"은 검토 범위를 뜻한다** — 전 대사를 JP 원문과 1:1로 대조하며, 명백한 오탈자·오역뿐
아니라 원문 뉘앙스에서 멀어진 표현(1-2)까지 교정 대상으로 본다.

**저본을 버린 새 번역은 아니다.** JP만 보고 처음부터 옮기는 게 아니라 기존 번역을 읽으며
원문과 대조해 고치고, 살아남은 어휘 선택과 문체의 뼈대는 정식판의 것이다. 고칠 근거가 없으면
그대로 둔다.

기술적 제약(바이트 길이, 세 가지 텍스트 포맷 등)은 [`../../NOTES.md`](../../NOTES.md) 참고. 이 문서는 "무엇을 어떻게 고치는가"만 다룬다.

**함께 볼 문서 — 시리즈 공통 지침**: 자매 프로젝트 `gensei-pc98`의
[`translation/GUIDE.md`](../../../gensei-pc98/translation/GUIDE.md)에 환세 시리즈 전체의 공통
규칙이 있다. 취호전 등장인물(아타호·스마슈·린샹)의 말투표가 거기 4장에 있고, 판단 원칙(1장)과
이름·용어 규칙(3장)도 이 문서에 중복 수록하지 않았으므로 그쪽을 봐야 한다.

**단, 그 문서를 그대로 적용하면 안 된다.** 두 프로젝트는 전제가 반대다 — 시리즈 쪽은 PC-98
타이틀을 **새로 번역**하며 글자수(`len(line)`) 제약을 받고, 취호전은 **이미 나온 정식 번역을
고치며** CP949 **바이트** 제약을 받는다. 그래서 포맷 규칙은 정반대인 항목이 있다:

| 항목 | 시리즈 지침 | 취호전 |
|---|---|---|
| 문장부호 | 반각 `!` `?` (2-1) | **전각 `！` `？`만 쓴다** |
| 숫자 | 반각 `123` (2-1) | **전각 `１２３`만 쓴다** |
| 공백 | 일반 공백 (2-1) | **전각 `　`(U+3000)만 쓴다** |
| 쉼표 | 배제 (2-6) | **쓴다** (2-3의 조건 아래) |
| 더듬음 구분자 | 일반 공백 (2-5) | **쉼표 `，`** — `뭐，뭐라구` (2-6) |

(왼쪽 절 번호는 시리즈 지침 기준, 오른쪽 괄호는 이 문서 기준이다.) 취호전 코퍼스에는 반각
문자가 **하나도 없다** — 전각/반각은 취향이 아니라 게임 폰트 문제라, 반각이 섞이면 글자가
깨진다(2-3 물결표 항목과 같은 이유). 마지막 행이 특히 함정이다 — 시리즈 규칙을 그대로 믿고
더듬음을 공백으로 넣으면 취호전에서는 **오히려 결함을 만든다**.

반대로 **그대로 통하는 것**: 이름류 붙여쓰기(시리즈 3장 ↔ 이 문서 2-1), 호칭 접미사 붙여쓰기
(시리즈 3-5 — 취호전도 `린샹님`처럼 붙여 쓰며 띄어 쓴 예가 없다), 웃음소리 음차(시리즈 3-7 →
이 문서 5-7), 그리고 **1장 판단 원칙 전반**(아래 1-2·1-4에 취호전 맥락으로 옮겨 적었다).

원칙적으로 **충돌하면 취호전 코퍼스의 기존 관례가 우선**한다 — 이미 나온 번역의 일관성이
새 번역용 규칙보다 앞선다.

수정의 성격은 **3층위**(① 오역 정정 → ② 원문 뉘앙스 교정 → ③ 표기·맞춤법 정정, 심각도 순 —
정의는 NOTES.md "KR 정식 번역 전면 개정" 참고)로 분류하며, 패치 노트도 이 층위로 쓴다. 이
문서의 장 구성과의 대응: 1-2·1-4·4·6장 판단이 주로 ①·②, 2·3장 규칙과 5장 용어 통일이 주로
③에 해당(다만 5장에서 원래 단어를 다른 단어로 바꾸는 항목은 ①·②이기도 하다).

## 1. 작업 원칙

### 1-1 우선순위: JP 원문 > 기존 KR 번역

판단 기준의 우선순위는 **1순위 JP 원문의 의미, 2순위 기존 KR 번역의 표현·스타일**이다. 기존
KR 번역은 유지가 기본값이지만, JP 원문과 어긋나면 원문 쪽을 따른다 — 명백한 오역뿐 아니라
**1-2의 ②층위(과한 의역·뭉갬) 양방향까지 교정 대상**이다.

**단, 바꾸는 쪽에 근거가 있어야 한다.** JP 원문 대조라는 근거가 있을 때만 바꾸고, 근거 없이
"이렇게 쓰는 게 더 낫겠다"는 취향은 근거가 아니다. 판단이 갈리면 기존 번역을 남긴다.

### 1-2 원문에서 멀어진 번역 되돌리기 (양방향)

②층위(뉘앙스 교정)는 **과한 쪽과 덜한 쪽 양방향**이다 — 원문에 없는 것을 얹은 경우와, 원문에
있는 것을 뭉개버린 경우 둘 다 교정 대상이다.

**⒜ 과한 의역 — 원문에 없는 정보량을 얹은 경우.** JP에 없는 슬랭·과장 표현을 끼워 넣거나,
쉬운 말을 괜히 어렵게/기교 있게 옮긴 것.

| JP | 기존 번역 (과한 의역) | KR 수정 |
|---|---|---|
| 井戸水 | 정호수 | 우물물 |
| 実用性は大幅アップ！ | 실용성은 왕따봉! | 실용성은 대폭상승 |
| 防御力大幅アップ | 방어효과 따봉인 도복 | 방어효과가 높은 도복 |
| 妙なことを言うな！ | 괜한　상상일랑　하지　말게！ | 이상한　소리를　하지　말게！ |

마지막 예는 두 군데가 어긋났다 — `妙な`(이상한)를 `괜한`(불필요한)으로, `言う`(말하다)를
`상상`(생각하다)으로 바꿔 상대가 **입 밖에 낸** 것에 대한 반응이라는 맥락까지 흐려졌다.

**⒝ 뭉갠 번역 — 원문에 있는 것을 빠뜨린 경우.** 특히 농담·대비의 낙차를 만드는 핵심 단어가
사라지면 장면이 성립하지 않는다.

| JP | 기존 번역 (뭉갬) | KR 수정 |
|---|---|---|
| 立派な患者じゃよ | 환자라구！！ | 어엿한 환자라구|

`立派な`(어엿한)가 빠지면 "누더기처럼 보여도 **어엿한** 환자"라는 대비가 사라져 농담이 죽는다.

**판단 원칙** (시리즈 지침 1-2에서 — 취호전에도 그대로 적용):

- **근거는 사전 의미가 아니라 게임 내 실제 연출·상황이다.** 사전에 여러 뜻이 있으면 그 장면에서
  실제로 무슨 일이 벌어지는지로 고른다.
- **직역이 한국어로 성립하는 관용구는 한국어 관용구로 갈아끼우지 않는다.** 관용 대 관용이 정답이
  아니다 — 직역이 통하면 직역이 우선.
- **길이를 줄일 때도 핵심 어휘는 직역으로 지킨다.** 지시어·조사 등 군더더기부터 덜어낸다
  (버리는 순서는 1-3 참고).

### 1-3 바이트 길이 제약

- `dialogue`: 원문과 **정확히 같은 바이트 길이**. 짧아진 만큼 전각 공백(`　`)으로 채운다.
- `labels`: 원문 길이 **이하**만 허용 (에디터가 전각 공백으로 자동 패딩). 늘릴 수 없다.

길이를 맞추기 위해 조사·어미를 바꾸거나 문장을 재구성하는 경우가 많다 (예: "…모른다．" → "…모른다　", 마침표를 지우고 공백으로 채움 — 자세한 이유는 2-3 참고). 자세한 배경은 NOTES.md 참고.

**여유 기준은 JP가 아니라 KR 원본 슬롯이다.** 제약은 기존 KR 번역이 차지하던 바이트 수이므로,
원본이 장황했다면 조여서 자리를 벌 수 있고 원본이 이미 빡빡하면 쓸 수 있는 자리가 없다.

**버퍼가 빠듯할 때 버리는 순서** — 위쪽을 지키고 아래쪽부터 버린다:

1. **핵심 의미** — 절대 버리지 않는다. 이걸 버리면 ①층위 오역이 된다.
2. **화자 말투·서법** — 캐릭터 정체성이라 가급적 지킨다 (1-4, 4장).
3. **부차적 연출** — 더듬음, 감탄사, 늘임, 리듬. 자리가 없으면 **버려도 되고, 버린 것을 결함으로
   보지 않는다**.

이 순서 때문에 JP의 더듬음이 KR에서 사라진 줄이 상당수 있지만 수정 대상이 아니다(2-6 참고).
거꾸로 **자리가 남으면 3번까지 되살린다** — 여유가 있는데도 빠져 있으면 그때 채워 넣는다.

**검토 라운드의 분업**: 의미 검토 단계에서는 직역·원문 충실을 우선해 안을 받고, 바이트 길이
조정은 반영 단계에서 따로 처리한다. 검토 중에 길이를 맞추려 미리 압축하면 의미가 깎이므로,
압축은 최후 단계에서 한다.

### 1-4 서법 보존

4장이 존댓말/반말이라는 **굵은 축**을 다룬다면, 서법은 그보다 **가는 축**이다 — 추측·납득·정중·
존경을 원문보다 거칠게도, 정중하게도 평탄화하지 않는다. (시리즈 지침 1-5에서 — 전면 적용)

- **없는 존경을 덧칠하지 않는다.** 단순 정중 과거(`~しました`)는 `했군요`지 `하셨군요`가 아니다.
  존경 어미(`~される`/`なさる`/`いらっしゃる`)가 JP에 실제로 있을 때만 `-시-`를 쓴다.

  | offset | JP | KR | 존경 축 |
  |---|---|---|---|
  | 319062 | `見事クリアーしました！` | `훌륭하게　클리어했군요！` | 덧칠 없음 ○ |
  | 965730 | (동일) | `훌륭하게　클리어하셨군요` | 덧칠 ✗ |
  | 1205734 | (동일) | `멋지게　클리어하셨습니다！` | 덧칠 ✗ + 어휘 불일치 |

  같은 원문 한 줄이 세 갈래로 갈렸다 — 서법 문제이면서 동시에 5장(동일 대상 표기 통일)
  문제다. **단, 위 표는 존경 축만 본 것이고 셋 다 완성형이 아니다** — 이 줄들은 화자 없는
  획득·완료 안내라 2-4(시스템 메시지는 평서체)도 걸린다. 두 규칙을 다 적용하면 `클리어했다`가
  되고, 실제로 같은 부류의 안내문은 대부분 평서체로 정리돼 있다. **한 줄에 여러 규칙이 겹칠 수
  있으니 한 축만 보고 "이제 맞다"고 끝내지 말 것.**

- **문장 종류를 바꾸지 않는다.** 단어가 비슷해도 문장 종류가 달라지면 캐릭터의 태도와 장면의
  톤이 바뀐다. 말끝(어미)의 기능을 원문 그대로 살린다.

  | 원문 서법 | 잘못 바뀌는 방향 | 살려야 할 말끝 |
  |---|---|---|
  | 추측 `~ようだ`·`らしい`·`かもしれん`·`じゃろう` | 단정 | `~듯하군` / `~것 같군` / `~인 모양이다` / `~지도 모른다` |
  | 권유·허락 `~がよい`·`~ましょう` | 명령 | `~하는 게 좋다` / `~해 보지 않겠나` |
  | 의문·여운 `~のか`·`~かな` | 감탄·단정 | `~하는 건가` / `~하려나` |

  이 항목은 1-2⒜(없는 표현을 얹는 과잉 의역)와 별개 유형이다 — 정보량은 그대로인데 서법만
  틀어진 경우라 눈에 잘 안 띈다.
- **인물 간 상하관계와 타인의 죽음은 높임에 반영한다** — `死んだお母さん` → `돌아가신 어머니`.
- **정중체 화자라도 혼잣말로 납득하는 자리는 반말이 맞다** — `그렇군`. 어미 일관성보다 서법이 우선.

> 주의: 위 조건들은 기계로 후보를 뽑아도 **오탐이 많다**(`素晴らしい`가 `らしい`에 걸리는 식,
> KR의 `~라네`/`~모양이네`도 추측 표지인데 놓치는 식). 반드시 화자와 상대 관계를 확인하고
> 판단할 것 — 조건에 걸렸다는 이유만으로 고치지 않는다.

## 2. 표기 규칙

### 2-1 복합 명사는 붙여 쓴다

아이템명·기술명·지명·호칭처럼 고유명사로 기능하는 "OO의 OO", "OO OO" 형태는 띄어쓰기를 없애고 붙여 쓴다. 원문(정식 번역)은 띄어 쓴 경우가 많았지만, 고유명사 취급을 위해 통일한다.

| 기존 번역 | KR 수정 |
|---|---|
| 호랑이 발톱 | 호랑이발톱 |
| 나찰의 도복 | 나찰의도복 |
| 나찰의 흉인 | 나찰의흉인 |
| 표범의 발톱 | 표범발톱 |
| 호랑이 투의, 호랑이 도복 | 호랑이투의 |
| 백호의 투의, 백호 도복 | 백호투의 |
| 달인의 무투복 | 달인의무투복 |
| 투신의 갑옷 | 투신의갑옷 |
| 가죽 갑옷 | 가죽갑옷 |
| 철편 갑옷 | 철편갑옷 |
| 어설트 슈트 | 어설트슈트 |
| 불타는 마검 | 불타는마검 |
| 마취 대작전 | 마취대작전 |
| 고양이 발톱 | 고양이발톱 |
| 쿵푸 드레스 | 쿵푸드레스 |
| 백호권 사범 | 백호권사범 |

지명도 동일 원칙: `호랑이 굴` / `호랑이 동굴` → `호랑이동굴`, `지옥 입구` → `나락입구` 등.

### 2-2 외래어 표기

외국어 음역은 국립국어원 외래어 표기법(장음 처리 등) 기준으로 통일한다. 판단이 아니라 규정을 따르는 문제라 표기 규칙 쪽에 둔다.

| JP | 기존 번역 | KR 수정 |
|---|---|---|
| ハンマー (hammer) | 햄머 | 해머 |
| ローキック (low kick) | 로 킥 | 로우킥 |
| デスドラゴン (death dragon) | 데드드래곤 | 데스드래곤 |
| モンスター (monster) | 몬스타 | 몬스터 |

### 2-3 문장부호

- 문장 끝의 마침표(．)는 제거하고 남는 자리는 전각 공백으로 채운다. **허용되는 문장 끝 부호는 ！ ？ … 뿐**, 마침표는 쓰지 않는다.
  - 예: `모른다．` → `모른다　` / `있습니다．` → `있습니다　` / `됩니다．` → `됩니다　`
- 쉼표(，)는 원칙적으로 유지하되, **짧은 감탄사·호칭 뒤에 습관적으로 붙는 쉼표는 제거하고
  전각 공백으로 대체**한다(자리가 남으면 그만큼 뒤에 공백 추가).
  - 예: `「호호，역시　당신은` → `「호호　역시　당신은` / `하지만，아무도` → `하지만　아무도`
  - 열거·전환("즉，", "그럼，" 뒤에 실제 설명이 이어지는 경우 등) 쉼표는 그대로 유지.
- 마침표 제거로 남는 공백은 다음 줄과 이어지는 자리이므로 실수로 다른 글자를 채우지 않도록 주의.
- **JP 대비 문장부호 과잉은 교정 대상**이다. 다만 **유형별로 우선순위가 다르니** 아래 구분을
  지킬 것 — 특히 일괄 검토를 돌릴 때 3순위까지 전부 손대면 안 된다.

  | 유형 | 예 | 우선순위 |
  |---|---|---|
  | JP에 없는 부호를 넣고 **반복까지** 함 | JP 무마크 → KR `！！` | **1순위 — 고친다** |
  | JP에도 있으나 KR이 **더 길게** 반복 | JP `！` → KR `！！` | **2순위 — 고친다** |
  | 문장 끝 **마크 종류**가 다름 | JP `？` → KR `！` | **2순위 — 고친다** |
  | JP에 없는 부호를 **하나** 넣음(반복 없음) | JP 무마크 → KR `！` | **3순위 — 일괄로 고치지 않는다** |

  3순위는 규칙에서 빠진 게 아니라 **손대는 순서가 맨 뒤**라는 뜻이다. 해당 줄이 워낙 많아
  후보를 좁혀주지 못하고(전체를 훑는 것과 다를 바 없음), 다른 대사를 고치는 김에 같이 처리되는
  종류다. **이것만 걸린 줄을 찾아다니며 고치지 말 것.**
  - 1·2순위 후보는 에디터 필터 **문장부호 › 추가+반복 / 반복 증폭 / 끝 어조 불일치**가
    추려준다. 3순위는 그래서 필터 옵션이 없다(판정 함수 `punct-added`는 살아 있어, 필요하면
    `editor.html`의 `FILTERS` 레지스트리에 한 줄 되살리면 된다).
  - **끝 어조 불일치는 두 부류가 섞여 있다.** JP `…` → KR `？！`처럼 마크 종류가 실제로 다른
    줄(약 229건)이 본래 대상이고, JP `！？` → KR `？！`처럼 **부호 조합은 같고 순서만 뒤집힌**
    줄(약 28건)도 같이 걸린다. 후자는 위 표의 "마크 종류가 다름"에 해당하지 않으므로 우선순위
    밖으로 보고 넘겨도 된다.
- **물결표는 `∼`(U+223C)만 쓴다**: KR판 원문이 전부 U+223C를 쓰므로 `～`(U+FF5E, JP판 관례)나
  `~`(반각)가 섞이면 게임 폰트에서 다른 글자로 렌더링된다. 에디터가 입력 시 자동 치환하지만,
  외부에서 붙여 넣은 텍스트는 주의.

### 2-4 시스템 메시지는 평서체

조작키는 `「」`로 감싼다. 물리 키 이름(스페이스키 등)은 게임 내 논리 버튼명으로 바꾼다.

### 2-6 더듬는 대사

JP는 더듬는 음절 뒤에 전각공백(　)을 쓰지만(`な　なんだって`), 이 게임 KR 정식 번역은
공백이 아니라 **쉼표(，)**로 반복 음절을 잇는 것이 확립된 관례다(`뭐，뭐라구`). 시리즈 공통
지침(`gensei-pc98/translation/GUIDE.md` 2-5)은 반각 공백을 쓰지만, 그건 새로 번역하는
PC-98 타이틀 기준이고 취호전은 이미 나온 정식 번역의 결함을 고치는 작업이라 **취호전
코퍼스 자체의 기존 관례(쉼표)를 우선**한다. 2-3의 "습관적 쉼표 제거" 규칙은 여기 해당
안 됨 — 이 쉼표는 더듬음을 나타내는 기능적 부호이므로 유지·통일 대상.

| JP | KR |
|---|---|
| `な　なんだって！？` | `뭐，뭐라구！？` |
| `い　いや　なんでもない…` | `아，아냐，아무　것도…` |
| `た　助けてーっ！！` | `도，도와줘요－！！` |
| `く　苦しい…` | `괴…괴로워…`（숨찬 신음은 쉼표 대신 말줄임표도 허용） |

**결함 패턴**: JP는 더듬음인데 KR이 반복은 했으면서 구분자로 전각공백을 쓴 경우(`너　너희들은` 등,
쉼표여야 함)는 표기 불일치로 수정 대상 — 에디터 "더듬음 공백" 필터로 후보 확인.

**결함이 아닌 것 — 더듬음 생략**: JP가 더듬는데 KR은 그냥 평문으로 옮긴 줄이 상당수 있지만
**수정 대상이 아니다**. 더듬음을 재현하면 반복 음절 + 쉼표로 4바이트(전각 2자)를 쓰는데, 길이
제약이 KR 원본 슬롯 기준이라 그만큼 실제 내용을 담을 자리가 줄어든다(`뭐라고` 6바이트 →
`뭐，뭐라고` 10바이트). 버퍼가 빠듯한 줄에서 더듬음을 버리고 내용을 살린 것은 제약 아래의 옳은
선택이다. **버퍼에 여유가 있을 때만 살린다** — 자리가 남는데도 빠져 있으면 그때 채운다.
여유 판단에는 바이트 계산이 필요하므로 이건 **반영 단계에서 할 일**이다(1-3 "검토 라운드의
분업"). 의미 검토 단계에서는 더듬음 생략을 결함으로 올리지 않는다.

## 4. 화자 말투 (존댓말/반말)

**같은 화자가 같은 상대에게 말하는데 존댓말·반말이 뒤섞이면 통일한다.** 기준은 JP 원문의
어체 — JP가 반말(だ·ぜ·な·のか·オレ 등)인데 KR만 존댓말(~요/~죠/~습니다)로 옮긴 경우가 특히
많으니, JP를 기준으로 반말로 되돌린다. 반대로 JP가 존댓말(です·ます·ください)이면 KR 존댓말이
맞는 것이니 건드리지 않는다.

**캐릭터별 확정 어미는 시리즈 공통 지침 4장**(문서 서두 링크)**을 따른다** — 아타호·스마슈·
린샹 모두 거기 등재돼 있다. 아래는 취호전에서 추가로 확인된 사항만.

- **스마슈**: 아타호("아저씨")·린샹에게 **반말**이 기본. 원판 번역에 스마슈가 이들에게
  존댓말 쓰는 오류가 다수 있어 전수 교정함(예: `아무것도　없어요` ← `カラッポだぜ` →
  `아무것도　없어`, `끝난　건가요？！` ← `終わりかよ` → `끝난　거야？！`).
- **린샹 — 기존 톤 바탕, 부분적으로 반존대(확정)**: 원판 번역은 린샹 대사를 광범위하게
  존댓말로 옮겨놨다. 시리즈 지침 4장의 "당찬 반말"과 어긋나 보여 오래 판단을 보류했던
  항목인데, **일괄 반말도 일괄 존대 유지도 아니고, 기존 존대 톤을 기본 바탕으로 삼되 문맥상
  자연스러운 곳은 반존대(완전한 `~습니다`체가 아니라 존대·반말 중간의 어조)로 부분 교정**하는
  것으로 확정했다.

  > **근거**: 여성체 종조사(`わ`·`わよ`·`よ`·`のね`)의 상냥한 어조를 한국어 존대로 옮기는 것도
  > 실제로 쓰이는 방식이라, JP 반말 어미와 정면으로 어긋났던 스마슈의 존댓말 오류처럼 기계적
  > 일괄 교정 대상은 아니다. 그렇다고 전부 그대로 두기엔 문맥상 반존대가 더 자연스러운 줄들이
  > 있어, **줄 단위로 판단**한다 — 상대(아타호/스마슈/그 외)나 존대 어미 유무만으로 자동
  > 분류할 수 있는 규칙이 아니다.
  >
  > **주의 — 화자 라벨이 이름이 아닐 수 있다**: 린샹은 대부분 JP 화자줄 `リンシャン`으로
  > 표시되지만, 일부 장면(예: 오프셋 1140120대)은 `猫耳の女拳士`(고양이귀 여권사)라는 별칭
  > 화자줄로 나온다. 화자 판별을 자동화하거나 특정 장면을 찾을 때 이름만으로 걸러내면 이런
  > 별칭 장면을 놓친다.
  >
  > 기계적 감지는 이 판단을 대신할 수 없다(존대 어미 유무만으로는 "의도한 반존대"와 "놓친
  > 실수"를 구분 못 함) — 에디터에 전용 필터를 만들지 않는다. 줄 단위 재검토는 계속 열려
  > 있으며, 진행 중인 작업이니 손보다가 멈춰도 된다.
- **주의 — 같은 존댓말 어미라도 화자를 반드시 확인**: 시스템 메뉴/안내문(`열어볼까요？` ←
  `あけますか？`, `결정　버튼을　눌러주세요` ← `ボタンを押してください`)은 화자 대사가 아니라
  존댓말이 맞음. 상점·여관 주인, 간호사 등 **원래 존댓말 캐릭터**의 대사도 그대로 둔다.
  화자 판별은 대사 바로 앞의 화자 이름 줄 + JP 어체(여성체 わ·わね·かしら·のね=린샹,
  노인체 じゃ·のう·わい=아타호/다리오스)로 교차 확인.
- **주고받는 대사는 짝을 맞춰 대구를 살린다**(시리즈 지침 1-4): 앞 대사의 단어를 뒤 대사가
  그대로 받아쳐야 대비가 산다. 한쪽만 고치면 짝이 깨지므로, 대사를 수정할 때 **앞뒤 줄을 같이
  본다** — 에디터 맥락 패널이 이 확인용이다.
- **장면 단위로도 톤을 본다** — 같은 장면의 주변 대사와 어긋나지 않는지 확인.

### 4-1 주연 3인 말투

시리즈 지침 4장과 같은 내용이지만, 이 문서만 보고도 작업할 수 있도록 취호전 코퍼스로 확인해
다시 싣는다. 어미는 실제로 많이 쓰인 것부터.

| 캐릭터 | 기본 | KR 어미 | 1인칭·호칭 | 취호전 현황 |
|---|---|---|---|---|
| **아타호** | 호랑이민족 권사, 중년 남성. 느긋한 **반말** | `~야` `~네` `~잖아` `~거야` `~겠지` `~라고` `~일세` `~함세` `~구먼` | `ワシ`→`나`/`난`/`내`, `お主`→**`자네`** | 대체로 정착됨 |
| **스마슈** | 개민족 검사, 젊은 남성. 경박한 **반말** | `~야` `~잖아` `~네` `~거야` `~라고` `~다구` `~냐?` | 아타호를 `おっさん`→**`아저씨`** | 존댓말 오류 **전수 교정 완료** |
| **린샹** | 고양이귀 격투가, 젊은 여성. 존대 바탕에 **부분 반존대** | `~요` `~죠` `~어요` `~네요`(기본) / 문맥에 따라 반존대 어미 | — | **줄 단위로 진행 중** (위 항목) |

시리즈 지침 4장은 린샹을 "당찬 반말"로 적고 있으나, 취호전 원판 번역은 존대로 옮겼다. 일괄
반말도 일괄 존대 유지도 아니고 **기존 존대 톤을 바탕으로 문맥상 자연스러운 곳만 반존대로**
줄 단위 교정 중이다(위 항목의 근거 참고). 화자줄이 `リンシャン`이 아니라 `猫耳の女拳士`인
장면도 있으니 놓치지 말 것.

### 4-2 취호전 조연·보스 말투

**취호전에만 나오는 화자**를 코퍼스에서 확인해 정리한 것이다.

| 화자 (JP) | JP 어체 단서 | KR 말투 | 비고 |
|---|---|---|---|
| 暗刻拳総統 | `だ`·`ぞ`·`ぬ` 단정 | 위엄 있는 평서 단정체 | 린샹·론·치호의 수장 |
| ロン / チーホー | 1인칭 `俺`, `ぜ` 반말 | **상대별 분기** — 총통에게는 존댓말, 그 외에는 반말 | 아래 설명 참고 |
| 大会主催者 | 여성체 `わ`·`わね`·`かしら`·`ですわね` | 격식 있는 여성 존댓말 | |
| 白虎 | `です`·`~のですが` **정중체** | 존댓말 | **사수(四獸) 중 유일**하게 정중체 |
| 朱雀 | `ほほほ` + `かえ`·`ぞよ`, 자칭 `わらわ` | 여성 노인체 (`~겠는가`/`~하게`) | `わらわ`→`우리`(위엄의 복수) |
| 玄武 | `ガハハ` + 남성 반말 | 호탕한 반말 | 웃음 `크하하하` |
| 蒼龍 | `うわっはっは`, 자칭 `わし` | 노인 남성 반말 | 웃음 `우하하하`, `わし`→`나` |
| 白虎拳師範 | `な`·`ぞ`·`ぢゃ` | 하게체 노인 | `修業は終わりぢゃ`→`수련은　끝이라네` |
| 老人 | `ふぉっふぉっふぉ`, `わし`, `おぬし` | 하게체 노인 | 웃음 `허허허허`, `おぬし`→`자네`(시리즈 3-5) |
| 看護婦 | `です`·`ますけど` | 정중 존댓말 | **원래 존댓말 캐릭터** — 반말 환원 대상 아님 |
| 酒場のオヤジ | 남성 구어 반말 | 반말 | |
| アニキ | `だぜ`·`ぜ` 거친 반말 | 거친 반말 | 머슬룸 파수꾼. 화자명 표기는 `형님` |

**론·치호의 상대별 분기**가 특히 헷갈린다 — JP는 양쪽 다 `ぜ` 반말인데 KR은 상대를 보고 갈린다.
JP 어미만 보고 반말로 환원하면 안 된다.

| JP | KR | 상대 |
|---|---|---|
| `「…俺は総統についていくぜ` | `「…저는　총통님　뒤를　따르겠습니다` | 총통 → 존댓말 |
| `「まだ　帰ってきていないぜ` | `「아직　돌아오지　않았어` | 그 외 → 반말 |

**시리즈 카메오**: 알리바바·다리오스·페톰·키리·화린도 취호전에 등장한다. 이들의 말투는
시리즈 지침 4장을 그대로 따르므로 여기에 중복 수록하지 않는다.

### 5-7 웃음소리·감탄사

**웃음소리는 음차 통일** — 시리즈 지침 3-7과 동일하고, 취호전 코퍼스에서도 이미 예외 없이
지켜지고 있다. 새로 손댈 때도 이 표기를 따른다.

| JP | KR | | JP | KR |
|---|---|---|---|---|
| ホホホ / ほほほ | 호호호 | | フフフ / ふふふ | 후후후 |
| ハハハ / はっはっは | 하하하 | | ケケケ | 케케케 |
| ヒッヒッヒ | 힛히히 | | イヒヒ | 이히히 |
| ほっほ (노인) | 허허 / 호호 | | ふぉふぉ (노인) | 흐흐 / 후후후 |

**감탄사는 기본값일 뿐, 편차가 곧 결함은 아니다.** 시리즈 지침 3-7의 매핑(`ちっ`→`쳇`,
`あら`→`어머`, `なるほど`→`과연/그렇군`, `ちくしょう`→`제기랄/젠장`, `おお`→`오/오오`,
`くっ`→`흡`, `ふっ`→`훗`)을 기본으로 삼되, 취호전 코퍼스는 실제로 갈린다 — 같은 `ちっ`가
`쳇`이기도 하고 아예 빠지기도 하며, `ちくしょう`는 `제기랄`과 짧은 `제길`이 섞여 있다.
**버퍼가 좁아 짧은 이형을 썼거나 감탄사 자체를 버린 경우가 많아**(1-3의 버리는 순서 3번),
매핑과 다르다는 이유만으로 고치지 않는다. 자리가 넉넉한데 어긋난 경우만 기본값으로 되돌린다.
