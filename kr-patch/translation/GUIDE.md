# 환세취호전 KR 번역 수정 지침

> 이 문서는 새 번역을 만드는 게 아니라, **정식 발매된 KR판 번역의 오탈자·오역을 교정**하는 작업의 기준을 정리한다.
> 작업하면서 발견한 규칙·용어·판단 기준을 여기에 계속 누적한다.

기술적 제약(바이트 길이, 세 가지 텍스트 포맷 등)은 [`../../NOTES.md`](../../NOTES.md) 참고. 이 문서는 "무엇을 어떻게 고치는가"만 다룬다.

---

## 1. 작업 원칙

### 1-1 우선순위: JP 원문 > 기존 KR 번역, 확실한 것만 수정

판단 기준의 우선순위는 **1순위 JP 원문의 의미, 2순위 기존 KR 번역의 표현·스타일**이다. 기존 KR 번역은 유지가 기본값이지만, JP 원문과 명백히 어긋나면 원문 쪽을 따른다. 이미 나온 정식 번역이므로 **명백한 오탈자·오역·표기 불일치**를 중심으로 고친다.

### 1-2 과한 의역 걷어내기

기존 KR 번역이 JP 원문에 없는 슬랭·과장된 표현을 끼워 넣거나, 쉬운 말을 괜히 어렵게/기교 있게 옮긴 경우는 원문 뜻에 맞게 걷어낸다. 원문에 없는 정보량을 얹은 과잉 번역을 되돌리는 것.

| JP | 기존 번역 (과한 의역) | KR 수정 |
|---|---|---|
| 井戸水 | 정호수 | 우물물 |
| (실용성 상승 표현) | 실용성은 왕따봉! | 실용성은 대폭상승 |
| (방어효과 표현) | 방어효과 따봉인 도복 | 방어효과가 높은 도복 |

### 1-3 바이트 길이 제약

- `dialogue`: 원문과 **정확히 같은 바이트 길이**. 짧아진 만큼 전각 공백(`　`)으로 채운다.
- `labels`: 원문 길이 **이하**만 허용 (에디터가 전각 공백으로 자동 패딩). 늘릴 수 없다.
- `fonts`: 32바이트 이하.

길이를 맞추기 위해 조사·어미를 바꾸거나 문장을 재구성하는 경우가 많다 (예: "…모른다．" → "…모른다　", 마침표를 지우고 공백으로 채움 — 자세한 이유는 2-3 참고). 자세한 배경은 NOTES.md 참고.

## 2. 표기 규칙

### 2-1 복합 명사는 붙여 쓴다

아이템명·기술명·지명처럼 고유명사로 기능하는 "OO의 OO", "OO OO" 형태는 띄어쓰기를 없애고 붙여 쓴다. 원문(정식 번역)은 띄어 쓴 경우가 많았지만, 고유명사 취급을 위해 통일한다.

| 기존 번역 | KR 수정 |
|---|---|
| 호랑이 발톱 | 호랑이발톱 |
| 나찰의 도복 | 나찰의도복 |
| 나찰의 흉인 | 나찰의흉인 |
| 표범의 발톱 | 표범발톱 |
| 호랑이 투의, 호랑이 도복 | 호랑이투의 |
| 백호의 투의, 백호 도복 | 백호투의 |
| 달인의 무투복 | 달인의무투복 |
| 투신의 갑옷 | 투신의갑옷 |
| 가죽 갑옷 | 가죽갑옷 |
| 철편 갑옷 | 철편갑옷 |
| 어설트 슈트 | 어설트슈트 |
| 불타는 마검 | 불타는마검 |
| 마취 대작전 | 마취대작전 |

지명도 동일 원칙: `호랑이 굴` / `호랑이 동굴` → `호랑이동굴`, `지옥 입구` → `나락입구` 등.

### 2-2 외래어 표기

외국어 음역은 국립국어원 외래어 표기법(장음 처리 등) 기준으로 통일한다. 판단이 아니라 규정을 따르는 문제라 표기 규칙 쪽에 둔다.

| JP | 기존 번역 | KR 수정 |
|---|---|---|
| ハンマー (hammer) | 햄머 | 해머 |
| ローキック (low kick) | 로 킥 | 로우킥 |
| デスドラゴン (death dragon) | 데드드래곤 | 데스드래곤 |
| モンスター (monster) | 몬스타 | 몬스터 |

### 2-3 문장부호

- 문장 끝의 마침표(．)는 제거하고 남는 자리는 전각 공백으로 채운다. **허용되는 문장 끝 부호는 ！ ？ … 뿐**, 마침표는 쓰지 않는다.
  - 예: `모른다．` → `모른다　` / `있습니다．` → `있습니다　` / `됩니다．` → `됩니다　`
- 쉼표(，)는 유지한다.
- 마침표 제거로 남는 공백은 다음 줄과 이어지는 자리이므로 실수로 다른 글자를 채우지 않도록 주의.

## 3. 오탈자

**판단이 필요 없는, 그냥 잘못 쓴 글자.** 의도한 단어 자체는 명백하고, 표기만 틀렸던 경우. 발견 즉시 전수 수정 대상.

| 기존 번역 | KR 수정 | 비고 |
|---|---|---|
| 아자씨 | 아저씨 | 전체 대사에서 반복되는 오타 |
| 겁장이 | 겁쟁이 | `-쟁이` 표기 오류 |
| 줏어버렸다 | 주워버렸다 | `줍다` 활용 오류 |
| 좋을껄 | 좋을걸 | |
| 희긔품 | 희귀품 | |
| 퍽전축 | 폭전축 | |
| 일격필충 | 일격필중 | |
| 지옥의 밑바다 | 나락의 밑바닥 | `밑바다`→`밑바닥` 오타. `지옥`→`나락` 자체는 용어 통일이니 4-1 참고 |
| 평소복 | 평상복 | |

## 6. 기타 메모

- 패치 버전 라벨(`환세취호전 ver.1.0` → `ver.1.1`)은 번역 교정이 아니라 패치 버전 표기 갱신이므로 이 지침 대상이 아님 — 별도 기록만.
- "완전히 취해서" → "꽐라가 되어서", "맛이 갔군?" → "드디어 발정" 처럼 상태 설명 문구가 원문 뉘앙스와 크게 어긋났던 사례는 개별 오역으로 보고 문맥 확인 후 수정. 이런 큰 폭의 재구성은 이 표에 다 담기 어려우니, 특이 사례가 쌓이면 별도 절을 만든다.
- 새로운 용어/오탈자 패턴을 발견하면 이 문서의 해당 절에 바로 추가할 것. 목록이 길어지면 절을 분리한다.
